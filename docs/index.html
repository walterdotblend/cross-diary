MODULAR EXTENSIONS ECOSYSTEM

Extensions Hub // Expand Your Sanctuary

Cross-Diary is powered by a decoupled Extensions Engine. Enable or pin extensions into your quick-access navigation wheel with zero performance loss.

⚡ 8 Built-in Extensions Active
🎵 ACTIVE

Pulse Audio

Integrated music player, ambient sound generator (rain, lo-fi, cafe), and real-time audio waveform.

Type: music_waveform
🧩 CORE

NoteBlocks Engine

Embed interactive widgets (checklists, counters, timers) anywhere in your text. Moves strictly line by line.

Type: note_widgets
🔐 ACTIVE

Encrypted Vaults

Password-protected private partitions with decoy notes, auto-lock timeout, and client-side encryption.

Type: vault_boveda
📋 ACTIVE

Universal Clipboard

Instant multi-device copy & paste sync between PC and Android, with custom device names and push actions.

Type: clipboard_hub
💻 ACTIVE

Custom CSS & AI Prompt

Direct CSS code injection with ready-made brutalist snippets and prompt helper for custom styling with any AI.

Type: custom_css
🎨 ACTIVE

Sticker Studio

Drag-and-drop freeform sticker canvas layer over notes with custom PNG/SVG uploads and multi-pack management.

Type: sticker_studio
⏱ ACTIVE

Chrono & Stopwatch

High-precision millisecond stopwatch with split lap logging and persistent countdown timers for sprint sessions.

Type: chrono_calc
🧮 ACTIVE

Calculator Pro

Quick floating expression solver and history ledger for budgeting, calculations, and tracking figures.

Type: calculator_pro
